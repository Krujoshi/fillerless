Fillerless: daily speaking practice (installable web app)

PUT IT ON YOUR PHONE
1. Host this folder on any HTTPS site (the microphone only works on HTTPS).
   Easiest: drag the whole folder onto https://app.netlify.com/drop
   (GitHub Pages or Cloudflare Pages also work).
2. Open the site on your phone.
   iPhone: Safari > Share > Add to Home Screen.
   Android: Chrome menu > Install app.
3. Allow the microphone when asked.

FILES
index.html, styles.css, app.js   the app
data.js                          passages, topics, questions and the path (edit freely)
sw.js, manifest.webmanifest      offline and install support
